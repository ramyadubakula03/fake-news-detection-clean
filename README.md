The Fake News Detection System is an AI-based web application that identifies whether a given news article is real or fake using Natural Language Processing (NLP) and Machine Learning techniques.
The system processes text data, extracts important features using TF-IDF vectorization, and classifies news using a Logistic Regression model.
A Flask-based web interface allows users to test news articles in real time.

Technologies Used :

Python
Machine Learning (Scikit-learn)
Natural Language Processing (NLP)
TF-IDF Vectorization
Logistic Regression
Flask (Web Framework)
Pandas, NumPy
Git & GitHub


Features :

Real-time news classification (Real / Fake)
NLP-based text preprocessing
TF-IDF feature extraction
Machine Learning model training
Web interface using Flask
High accuracy prediction

3)Train the model

5)Open in browser
>  >http://127.0.0.1:5000
